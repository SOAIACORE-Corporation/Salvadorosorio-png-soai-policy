# SOAiaCore · RADAR-CAL-01 · Phase B1

Status: COMPLETE / LEAKAGE-CONTROLLED RETROSPECTIVE
Date: 2026-08-17

## Objective
Compare a rigid literal criterion against the Flexible Psychosocial Inference Standard on primary microsequences before consulting the corresponding human adjudication sheet.

## Design
Sample: 20 microsequences across 4 dyads from `F4 Microsecuencias` in the canonical v9.1 psychosocial matrix.

Operational order used in this execution:
1. read/source microsequences;
2. classify with rigid and flexible criteria;
3. only afterwards inspect `F4 Validación`;
4. score semantic-pragmatic alignment.

Rigid criterion privileges literal domain labels and explicit directed wording.
Flexible criterion preserves signal while modeling target resolution, multi-addressee structure, irony/banter, pragmatic function, asymmetry and claim limits.

## Results
- N = 20 cases
- rigid exact semantic alignment = 12/20 = 60.0%
- flexible exact semantic alignment = 19/20 = 95.0%
- one additional flexible case = PARTIAL
- exact gain = +35 percentage points
- relative gain over rigid exact alignment = +58.3%

## Main error classes corrected by the flexible standard
1. Multi-target attribution: mentions were not automatically converted into dyadic care/desire/conflict.
2. Antagonistic banter: verbal aggression was retained as a signal without automatically inferring stable hostility.
3. Performative eroticization: public sexualized language was preserved without being promoted to proven private desire.
4. Authorized conceptual criticism: criticism could coexist with institutional alignment without forcing a personal-antagonism model.
5. Adjacency/lyrics contamination: song lyrics and nearby clauses were downweighted or rejected when target attribution was weak.

## Partial case
Antonio↔Jahir / care / rank 1. `Con cuidado no son juguetes` occurs inside a mock-weapons joke. The flexible criterion retained it as `CARE_PERFORMATIVE_LOW_WEIGHT`; human validation supports some direct care in the dyad but warns about banter/adjacency contamination. Scored PARTIAL rather than exact.

## Interpretation
The principal gain is not simply accepting more information. It is improving pragmatic meaning. The rigid method can detect surface domains while still misclassifying function: antagonism vs banter, desire vs public eroticization, mention vs actual target, lexical apology vs effective repair.

## Limitations
This is a within-session leakage-controlled retrospective, not an independent external blind trial. Source microsequences were evaluated before the human validation sheet was consulted in this execution, but the same system performed both stages. Sample is small and stratified, not random.

## Confidence
- methodological direction: MEDIUM-HIGH
- magnitude of the 60%→95% gain: MEDIUM pending larger randomized adjudication

## Next gate
Phase B2 should use a larger randomized sample, frozen pre-adjudication predictions, independent human/expert adjudication, and measure pattern recall, false-certainty rate, contradiction sensitivity, confidence calibration, inference reasonableness, and inter-rater agreement.
